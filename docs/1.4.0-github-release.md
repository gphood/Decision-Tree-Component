# Decision Tree 1.4.0 — Visual canvas builder

Decision Tree 1.4.0 adds a visual canvas for building and editing your decision trees in Joomla. Switch between the form builder and canvas while working on the same tree.

## What's new

- **Visual canvas:** see questions, outcomes and answer paths together, with drag-and-drop positioning, pan, zoom, fit and automatic arrangement.
- **Edit directly from the canvas:** open a question or jump to the option behind an outcome. Duplicate or delete questions and choose the start question from their cards.
- **Visible path warnings:** identify unreachable questions, missing destinations and incomplete options while reviewing the tree.
- **Saved layouts:** retain canvas positions when you save, with keyboard controls for moving and editing question cards.
- **Subtle Pro information:** a collapsible “What's in Pro” panel appears below the tree list in the Free edition.

## Improvements

- Consistent hover and keyboard-focus feedback for outcome buttons, including administrator previews.
- Improved preview navigation controls in light and dark modes.
- Updated editor layout and controls for working with questions and outcomes on the canvas.

The visual canvas is included in **Decision Tree Free**. Free continues to support one decision tree per site, with basic text and a call-to-action link in outcomes.

## Installation and updating

Download **`pkg_decisiontree-1.4.0.zip`** from this release and install it through **System → Install → Extensions**, or use Joomla's update system once the update is available. The package includes both the component and content plugin.

Back up your site before updating. There is no need to uninstall your existing version.

**For Pro users:** update Decision Tree Free to 1.4.0 first, then update Decision Tree Pro. Pro remains a separate add-on and requires the Free package to stay installed. Pro 1.4.0 adds image outcome blocks and previews from individual questions and outcomes.

Selecting **Done** in the canvas editing window updates your unsaved work. Use Joomla's main **Save** button to save the tree and its layout.

Compatible with Joomla 5 and Joomla 6; use a PHP version supported by your Joomla installation.
