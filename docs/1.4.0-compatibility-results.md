# Free-first compatibility evidence — 1.4.0

Verified 8 September 2026 using actual package installations on disposable local
copies with separate files and database tables. Original development sites were
not downgraded or edited by the upgrade tests.
All four temporary containers and all 370 temporary database table copies,
including the initial server-setup attempts, were removed after verification.

| Environment | Upgrade compatibility gate |
| --- | --- |
| Joomla 5.4.8 / PHP 8.4.20 / Chromium | Passed, 13.0 seconds, no skipped stages |
| Joomla 6.1.3 / PHP 8.4.20 / Chromium | Passed, 15.4 seconds, no skipped stages |

Each run performed this sequence:

1. Installed the archived Free and Pro 1.3.0 packages, saved a tree containing
   heading, text, list and button blocks plus fallback text/link data, and
   recorded a completed anonymous frontend run.
2. Attempted Pro 1.4.0 on Free 1.3.0. The installer refused it with the Free-first
   prerequisite message; versions and the existing analytics remained intact.
3. Installed Free 1.4.0 while retaining Pro 1.3.0. Verified rich content and
   previous analytics, edited outcomes in the canvas, duplicated a question,
   switched views, previewed outcomes, saved and reopened the tree, preserved
   layout, and duplicated the whole tree with its full outcome and layout data.
   Image and per-node preview controls were correctly absent. A new frontend
   completion was recorded alongside the old one; Back and Reset also worked.
4. Installed Pro 1.4.0. Mixed-version edits, layout and analytics survived. New
   canvas preview actions became available and rendered the saved outcome.
   Another real frontend completion was recorded.

The test rejects any uncaught administrator JavaScript errors. It caught a
canvas validation error before the fix: Joomla's validator accessed
`element.form` after the question input moved outside the form into its modal.
The input now explicitly retains its `tree-form` association. The regression
test focuses and blurs the field and checks that association. Both passes above
used the rebuilt package containing this fix.

## Repeat and scope

Run `npm run test:compatibility` with the disposable-site and package inputs in
`TESTING.md` on each supported Joomla major. The suite records the package hashes
in its `compatibility-versions` attachment. Local output directories for these
runs are `test-results/compatibility-joomla-5` and
`test-results/compatibility-joomla-6`.

PHP syntax validation of the changed template and `php tests/tree-validator.php`
also passed. The existing full browser suite on the rebuilt Joomla 6 / Pro 1.4.0
installation passed **16 tests in 39.5 seconds**, including the image/Media Manager
and rich-outcome canvas workflow. Its one intentional skip was the Free-only
boundary test because Pro was installed. Results are in
`test-results/current-pro-joomla6`.

This evidence completes the mixed-version gate. The remaining
release checklist still covers the wider matched-version/Free-only matrix,
image workflow, update keys, menu/article embedding and other installer cases.
