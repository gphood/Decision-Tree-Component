Guide visitors from a simple question to a useful next step.

Decision Tree Free helps people find the right information by asking a short series of questions. Create one tree for your Joomla site and use it for service guidance, product selection, support or frequently asked questions.

New in version 1.4.0

See the structure of your decision tree while you build it.

  • Visual canvas: view questions, outcomes and labelled answer paths together. Drag cards, pan, zoom, fit the tree or arrange it automatically.
  • Edit from the canvas: open a question or jump to the answer that produces an outcome. Duplicate questions, remove questions or choose a different starting point.
  • Visible path warnings: spot questions that cannot be reached, incomplete answers and missing connections.
  • Saved layouts: keep the arrangement when you save the tree.
  • Clearer buttons: consistent hover and keyboard-focus feedback for outcome links and preview navigation.

What Free includes

  • One decision tree per site, displayed in an article or through a Joomla menu item.
  • A form builder and visual canvas for the same tree.
  • Preview of the complete tree, including unsaved changes.
  • Individual question duplication and answer-option reordering.
  • Path validation and optional frontend step numbers.
  • Basic text outcomes with an optional call-to-action link.
  • JSON import/export and a copyable article embed tag.

Installing and updating

For Joomla 5 and Joomla 6. Use a PHP version supported by your installed Joomla version; the extension’s own minimum is PHP 8.1.

Install pkg_decisiontree-1.4.0.zip through System → Install → Extensions. The package includes the component and content plugin. When updating, back up your site and install over the existing version.
