Download Decision Tree Free 1.4.0 for Joomla.

The package contains the component and content plugin needed to create and display one decision tree, including the visual canvas.

Download Decision Tree Free 1.4.0

Package: pkg_decisiontree-1.4.0.zip

Requirements

For Joomla 5 and Joomla 6. Use a PHP version supported by your installed Joomla version; the extension’s own minimum is PHP 8.1.

Installation and updates

  1. Back up your site before updating an existing installation.
  2. In Joomla Administrator, open System → Install → Extensions.
  3. Upload the package ZIP. You do not need to unzip it or uninstall your existing version.
  4. Open Components → Decision Tree to create or edit your tree.

Once an update is available through Joomla, you can also install it from System → Update → Extensions.

Pro users: update Free to 1.4.0 first, then update Pro. Leave both packages installed.

Highlights in 1.4.0

  • Visual canvas with connected question and outcome cards.
  • Editing and question actions directly from the canvas.
  • Saved layouts and visible path warnings.
  • Improved button hover and keyboard-focus feedback.
