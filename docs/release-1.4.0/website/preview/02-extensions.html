Joomla extensions

Help visitors find the right information through clear, guided choices.

Decision Tree turns a series of questions into a useful route through your content. Both editions include the visual canvas introduced in version 1.4.0.

Decision Tree Pro

For websites with multiple guidance tools or more detailed outcomes.

  • Unlimited decision trees and whole-tree duplication.
  • Rich outcome blocks: headings, text, lists, images and buttons.
  • Preview from any question or jump directly to an outcome.
  • Optional anonymous analytics stored in your own Joomla database.

Decision Tree Free
