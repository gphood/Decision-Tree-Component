Decision Tree Free starter templates

Use these example trees as starting points for your own questions and outcomes. Each download is a Decision Tree JSON template that you can import and customise.

Before importing

  1. Export your current tree first if you want to keep a copy.
  2. Open Components → Decision Tree → Import JSON and choose the downloaded file.
  3. Use Preview Import to review it before making changes.
  4. If your Free site already contains one tree, choose Replace existing tree and confirm the replacement.
  5. Check the imported questions, outcomes and publication status, then save your changes.

Free allows one tree per site, including trees in Trash until they are permanently deleted. Pro also supports importing as a new tree.

In version 1.4.0, older templates can be opened in the visual canvas and arranged to suit your workflow.
