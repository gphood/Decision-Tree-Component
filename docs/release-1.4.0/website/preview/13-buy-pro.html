Buy Decision Tree Pro

Build multiple decision trees with richer outcomes and useful tools for managing larger Joomla websites.

Included in Pro 1.4.0

  • Unlimited decision trees and whole-tree duplication.
  • Rich outcomes with headings, text, lists, images and call-to-action buttons.
  • Previews from individual questions and outcomes.
  • Anonymous analytics with filters, CSV export and retention controls.
  • JSON import/export for reusing tree content.
  • The shared visual canvas, provided by Decision Tree Free.
  • All future Pro feature updates.

Pro is an add-on: install or update Decision Tree Free to 1.4.0 or later first, then install Decision Tree Pro 1.4.0. Keep both packages installed. Download Decision Tree Free if you need the base package.

For Joomla 5 and Joomla 6. Use a PHP version supported by your installed Joomla version; the extension’s own minimum is PHP 8.1.

Purchase and installation

Complete secure payment through Stripe. Your purchase email provides a secure download link and a persistent Joomla Download Key. No subscription is required.

Licence, Updates and Delivery

Licence

A single purchase allows you to use Decision Tree Pro on as many websites as you own or manage. There are no per-site licence fees.

Updates

Your purchase includes all future updates to Decision Tree Pro at no additional cost.

Delivery

After payment, you will receive an email containing a secure download link and a persistent Joomla Download Key. Enter the key once under System → Update → Update Sites so Joomla can install future Pro updates. The key does not expire or have a usage limit, but it should be kept private. If you experience any problems accessing your download or updates, please get in touch and I will be happy to help.

Because Decision Tree Pro is digital software delivered immediately after purchase, refunds are not normally available once the download has been accessed. This does not affect your statutory rights.
