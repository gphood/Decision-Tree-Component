# Visual Canvas

Decision Tree 1.4.0 adds a visual canvas to the administrator tree editor. It
is available in both Decision Tree Free and Decision Tree Pro on Joomla 5 and
Joomla 6.

## One tree, two editing views

Use **Form builder** for a focused question-by-question editor. Use **Visual
canvas** to see questions, outcomes and their connections together. Both views
edit the same unsaved tree data, so switching views does not copy, convert or
discard content.

The last selected view is remembered for the current browser session. When a
tree is saved with **Save**, the canvas view and page position are restored so
work can continue in the same place.

## Reading the canvas

- Question cards show the question text, option count and a **Start** badge on
  the current entry question.
- Outcome cards show a short preview and the answer option that reaches them.
- Connection labels show the answer text for each path.
- Warning and error badges identify unreachable questions, incomplete options
  and connections to missing questions. Select a badge to read the issue in
  plain language.

The canvas is an editing aid only. Moving cards changes their saved visual
positions, not the order or logic visitors experience on the frontend.

## Editing questions and outcomes

Double-click a question card or select **Edit question** to open it in the
canvas modal. The modal contains the same question and answer controls as the
form builder.

Select **Done** to close the modal and update the current unsaved tree. Select
Joomla's main **Save** button to persist tree content and canvas positions.

Select **Edit outcome** on an outcome card to open the same modal directly at
the option that produces that outcome. The relevant option is expanded,
scrolled into view and focused automatically. This works with Free's simple
outcomes and Pro's rich content blocks.

Each question card also provides these actions:

- **Duplicate question** creates a copy with new internal identifiers and opens
  it for editing.
- **Delete question** removes a non-start question after confirmation.
- **Set as start question** makes that question the tree's entry point.

The current start question cannot be deleted or set as start again. Change the
start question first if the existing start question needs to be removed.

## Navigation and layout

- Drag a question or outcome card to position it.
- Drag the empty canvas background to pan.
- Hold Ctrl on Windows/Linux or Command on macOS while scrolling to zoom.
- Use **Zoom in**, **Zoom out**, **Fit tree** and **Auto arrange** for precise
  viewport control.
- Focus a question card and use the arrow keys to move it. Press Enter to edit
  the focused question.

Canvas positions and viewport settings are stored in the tree's layout data.
Older trees without layout data are arranged automatically the first time the
canvas is opened.

## Free and Pro

The canvas, its question actions and validation warnings are shared Free
features. Decision Tree Free continues to support one tree with plain-text and
linked outcomes.

Decision Tree Pro adds unlimited trees, whole-tree duplication, rich outcome
blocks and first-party anonymous analytics. Rich outcome blocks can be edited
inside the canvas modal, including responsive images selected from Joomla's
Media Manager. Image blocks support alternative text or a decorative setting,
an optional caption and three display sizes. Only safe local JPEG, PNG, WebP and
AVIF files are accepted; configurable size and dimension limits help prevent
oversized images from reaching the frontend.

Pro question cards provide **Preview from here**, which previews the current
unsaved tree beginning at that question. Pro outcome cards provide **Preview
outcome**, which renders that outcome directly using the frontend result
renderer. Preview links cannot navigate away from the administrator. Complete
structured outcome data is retained when the canvas previews content,
duplicates a question, switches views, or saves and reloads the tree.

## Release validation

The 1.4.0 browser matrix covers Joomla 5 Pro, Joomla 6 Pro and Joomla 6
Free-only. It verifies canvas layout, actions, warnings, keyboard operation,
save/reload behavior, frontend rendering, Free edition boundaries and Pro rich
outcome preservation. The Pro runs also exercise Joomla's Media Manager, image
metadata and safety validation, per-question and per-outcome previews, and
image preservation after saving and reloading.
