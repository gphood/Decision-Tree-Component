# Decision Tree Pro 1.4.0

Released 8 September 2026. Requires Decision Tree Free 1.4.0 or later; update Free first and keep both packages installed.

## New in this release

- Image outcome blocks, with Joomla Media Manager selection, alternative text, decorative-image support, captions and display sizes.
- Preview from individual question cards and preview individual outcomes on the visual canvas.
- Rich outcomes remain available while editing from the shared canvas, with content preserved through editing, duplication and saving.

## Fixes and improvements

- Consistent hover and keyboard-focus feedback for rich-outcome buttons.
- Improved readability of the analytics settings button in light mode.
- Image dimensions and configured size limits help authors choose suitable files.

The visual canvas itself is included in Free. Anonymous analytics, unlimited trees, whole-tree duplication and the existing heading/text/list/button blocks continue from earlier Pro releases.
